# Alpine Snow

A Claude theme of snow-covered mountains for the Claude desktop and mobile apps.

- **Colors:** frosty blue-grays with a glacier-blue accent. Light mode is bright snow-glare white; dark mode is a moonlit navy.
- **Backdrop:** three snow-capped mountain ranges, drifting mist, pines and a snowfield, under two layers of slowly falling snow. A pale sun by day, a moon by night. Holds still for reduced motion.
- **Messages:** rounded, frosted bubbles and soft tool-call cards.
- **Sound** (off until you press the speaker in the session's title bar): soft wind and occasional faint chimes, with small ice-like cues.

The terminal and code editors don't draw themes.

## Install

At the prompt of a Claude Code terminal session:

```
/plugin install alpine-snow --marketplace Liffdog/alpine-snow-theme
```

Answer `y` to add the marketplace, then choose a scope (user is first).

From a shell:

```bash
claude plugin install alpine-snow --marketplace Liffdog/alpine-snow-theme
```

In the desktop app: click + next to the prompt box, then Plugins, Add marketplace with `Liffdog/alpine-snow-theme`, then Add plugin.
